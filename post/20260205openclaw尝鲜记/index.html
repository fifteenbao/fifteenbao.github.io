OpenClaw 尝鲜记

2026年2月5日 · fifteenbao
系列 · OpenClaw 尝鲜记

玩了三天风风火火的 OpenClaw/MoltBot/ClawdBot，还蛮好玩的，就是 Token 爆炸！ 尤其是那个 qwen3 max …… 随随便便一问，大几十万 token，问一下好几块…… 在此感谢阿里云送了150块优惠券🙏。

安装

用了阿里云和腾讯云的轻量化服务器，阿里云大模型的api调用默认打开的，第一天莫名其妙欠费8块…… 腾讯云倒是不会，而且版本也很新，看起来更新很快，像要把 channel、skill都封装进去，就是莫名其妙崩！暂时弃掉腾讯云了…… 等我的 mac mini 退休吧，给我的bot安个家，这线上的支出太可怕了。

关于模型

尝试了 qwen3 max / deepseek r1/v3.2 / GLM4.7 , 相对来说 qwen3好些（毕竟价钱在……） 切换了模型之后似乎记忆也有些问题…… 可能没重启之类的。

🦞 OpenClaw 核心插件库

消息与通信
• bluebubbles - BlueBubbles 集成
• discord - Discord 功能扩展
• slack - Slack 集成
• imsg - iMessage 支持
• wacli - WhatsApp CLI 工具

开发者工具
• github - GitHub 集成（issue、PR、CI 等）
• coding-agent - 编码助手
• tmux - Tmux 会话管理
• 1password - 1Password 集成

媒体与内容
• gemini - Google Gemini AI 集成
• openai-image-gen - OpenAI 图像生成
• openai-whisper - 语音转文字
• spotify-player - Spotify 控制
• songsee - 音乐识别
• gifgrep - GIF 搜索

生产力工具
• gog - Google Workspace 集成（Gmail、日历、Drive 等）
• notion - Notion 集成
• obsidian - Obsidian 笔记
• apple-notes - Apple Notes
• apple-reminders - Apple 提醒事项
• things-mac - Things 3 任务管理

系统与设备控制
• canvas - 实时画布控制
• camsnap - 摄像头快照
• openhue - Philips Hue 灯光控制
• sonoscli - Sonos 音响控制
• weather - 天气信息

实用工具
• clawhub - 插件管理 CLI
• skill-creator - 技能创建工具
• summarize - 内容摘要
• model-usage - 模型使用统计
• session-logs - 会话日志管理
