玩了三天风风火火的 OpenClaw/MoltBot/ClawdBot，接入了 telegram 和飞书，装了不少 skill；后来又部署到 RDK X5 的板子上，用 esp32 连了一个 so-arm-100 机械臂，并实现了语义控制。还蛮好玩的，就是 Token 爆炸！尤其是那个 qwen3 max …… 随随便便一问，大几十万 token，问一下好几块…… 在此感谢阿里云送了 150 块优惠券🙏。好玩、危险、费钱。它需要有个自己的 home。不知道咱家孩子以后能发展成什么样，很期待了。

下面先把当时用到的环境和配置说清楚，文末再放几次迭代里的具体案例。

环境和配置

安装

用了阿里云和腾讯云的轻量化服务器，阿里云大模型的 api 调用默认打开的，第一天莫名其妙欠费 8 块…… 腾讯云倒是不会，而且版本也很新，看起来更新很快，像要把 channel、skill 都封装进去，就是莫名其妙崩！暂时弃掉腾讯云了…… 本来想等 mac mini 退休，给 bot 安个家，这线上的支出太可怕了。后来没等 mac mini 退休，先把 OpenClaw 部署到了 RDK X5 的板子上。

板上用的是官方提供的 OpenClaw 一键安装脚本：curl -fsSL https://openclaw.ai/install.sh | bash

重启 Gateway：openclaw gateway restart

关于模型

尝试了 qwen3 max / deepseek r1/v3.2 / GLM4.7，相对来说 qwen3 好些（毕竟价钱在……）。切换了模型之后似乎记忆也有些问题…… 可能没重启之类的。板上跳舞时，模型用的是阿里云 7.9/月的 coding-plan qwen3 max，发傻的时候就切换到贵一点的 claude，调试通了，再切回来便宜的。

channel

接入了 telegram，帅呆！自定义了快捷菜单，目前看效果是不错，不知道会不会记忆混乱。感觉是个很不错的接入方式。

飞书，总是挂…… 等等官方新版支持效果。目前可以支持机器人创建飞书文档…… 它不给我开权限也是个问题……

硬件配置以及校准

参考：https://wiki.seeedstudio.com/lerobot_so100m_new/

3D 打印以及机械臂组装，按照 seeed 的教程安装了本地环境，并进行了机械校准（很重要！坏了两个电机🤷），并把校准文件地址提供给 OpenClaw 参考执行。

权限配置调整

2026.3.2 版本龙虾，默认只有 message 权限了。直接去改 openclaw.json 配置文件，把 tools.profile 的 message 修改为 full，重启 OpenClaw。
