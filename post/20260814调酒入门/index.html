调酒入门：认识六大基酒

Aug 14, 2026 · fifteenbao

大概有四个部分，常见酒单放在了前面，方便后面找；六大基酒介绍；常见的配角以及一些基本工具手法。

酒单

配比按总量 100ml 左右估算（单位 ml）；「搭」指搭配的柑橘/装饰

金酒

  • 金汤力：金酒 25 + 汤力水 75（1:3）（搭：青柠角）
  • 尼格罗尼：金酒 33 + 甜味美思 33 + 金巴利 33（1:1:1）（搭：橙皮）
  • 马天尼（Martini）：金酒 75 + 干味美思 25（3:1）（搭：柠檬皮/橄榄）

伏特加

  • 螺丝刀：伏特加 25 + 橙汁 75（1:3）（搭：橙片）
  • 血腥玛丽：伏特加 33 + 番茄汁 67 + 香料少许（搭：黄柠角）

威士忌

  • 教父：苏格兰威士忌 66 + 阿玛雷托 33（2:1）（搭：橙皮）
  • 古典：威士忌 60 + 方糖 1 块 + 苦精 3 滴 + 少量水（短饮，不按满杯计）（搭：橙皮 + 樱桃）
  • 曼哈顿（Manhattan）：威士忌 66 + 甜味美思 33 + 安高天娜苦精 2 滴（2:1）（搭：樱桃）
  • 威士忌酸（Whiskey Sour）：波本 50 + 黄柠汁 25 + 单糖浆 25（2:1:1，可选蛋清）（搭：黄 柠片/樱桃）
  • 萨泽拉克（Sazerac）：黑麦威士忌 60 + 方糖 1 块 + 裴乔氏苦精 3 滴 + 苦艾酒洗杯（短饮 ）（搭：柠檬皮）

朗姆酒

  • 莫吉托：白朗姆 40 + 青柠汁 20 + 糖/薄荷 + 苏打水约 40（搭：青柠、薄荷）
  • 自由古巴（Cuba Libre）：黑朗姆 30 + 青柠汁 10 + 可乐 60（搭：青柠角）
  • 代基里（Daiquiri）：白朗姆 50 + 青柠汁 33 + 单糖浆 17（3:2:1）（搭：青柠角）

Tiki 鸡尾酒

以朗姆为主角的热带风格：多朗姆混搭 + 果汁 + 糖浆，碎冰大杯、装饰华丽；以下按 100ml 估算

  • 迈泰（Mai Tai）：陈年朗姆 40 + 农业朗姆 5 + 青柠汁 27 + 橙皮甜酒 14 + 杏仁糖浆 7 + 糖浆 7（搭：青柠 + 薄荷）
  • 椰林飘香（Piña Colada）：白朗姆 25 + 椰浆 25 + 菠萝汁 50（搭：菠萝角）
  • 止痛剂（Painkiller）：朗姆 25 + 菠萝汁 45 + 橙汁 15 + 椰浆 15（搭：肉豆蔻 + 橙片）
  • 僵尸（Zombie）：白朗姆 40 + 黑朗姆 30 + 青柠汁 20 + 石榴糖浆 10（搭：青柠角 + 薄荷）

龙舌兰

  • 玛格丽特：龙舌兰 50 + 君度 25 + 青柠汁 25（2:1:1）（搭：青柠角 + 盐边）

白兰地

  • 边车：白兰地 50 + 君度 25 + 柠檬汁 25（2:1:1）（搭：黄柠皮/橙皮 twist）

利口酒 / 其他

  • 金巴利苏打（Campari & Soda）：金巴利 33 + 苏打水 67（1:2）（搭：橙片）

六大基酒

什么是六大基酒

绝大多数鸡尾酒都以某一种烈酒为主角，这个主角就叫「基酒」。鸡尾酒界公认的六大基酒是：

金酒 · 威士忌 · 白兰地 · 伏特加 · 朗姆酒 · 龙舌兰

基酒 原料 核心产区 代表调酒
金酒 谷物 + 杜松子等植物 英国 / 荷兰 金汤力、马天尼、内格罗尼
威士忌 谷物 + 橡木桶陈年 苏格兰 / 美国 / 日本 老式、曼哈顿、威士忌酸
白兰地 葡萄（及其他水果） 法国干邑 / 雅文邑 边车、白兰地亚历山大
伏特加 谷物 / 土豆 俄罗斯 / 波兰 / 瑞典 莫斯科骡子、血腥玛丽
朗姆酒 甘蔗 加勒比 / 巴西 莫吉托、代基里、自由古巴
龙舌兰 蓝色韦伯龙舌兰 墨西哥哈利斯科州 玛格丽特、龙舌兰日出

一、金酒（Gin）🍸

又称杜松子酒，鸡尾酒界使用最广的基酒，被称为「鸡尾酒的心脏」。

  • 成分：以谷物（大麦、玉米、黑麦等）酿制的中性烈酒为基础，用杜松子（Juniper）为主、辅以芫荽籽、当归、橙皮、柠檬皮、肉桂、鸢尾根等数十种植物进行加香蒸馏。法规要求杜松子风味必须在感官上占主导。
  • 分类：
    • 伦敦干金酒（London Dry）：最经典，风味干净、以杜松子为主，不得添加人工甜味剂
    • 老汤姆金酒（Old Tom）：微甜，介于伦敦干金与荷兰金酒之间
    • 荷兰金酒（Genever）：麦芽味重、口感更厚实，是金酒的鼻祖
    • 普利茅斯金酒（Plymouth Gin）：法定仅产自英国普利茅斯，口感更圆润
    • 新式金酒（New Western / Contemporary）：弱化杜松子，突出其他植物风味
  • 产区：荷兰为发源地，英国发扬光大并成为生产重镇；美国、西班牙、德国等全球各地都有出色酒厂。金酒是「不挑产地」的烈酒，几乎随处可产。
  • 主要品牌：添加利（Tanqueray）、必富达（Beefeater）、哥顿（Gordon’s）、孟买蓝宝石（Bombay Sapphire）、亨德里克斯（Hendrick’s）、猴王47（Monkey 47）、植物学家（The Botanist）
  • 代表调酒：金汤力（Gin & Tonic）、马天尼（Martini）、内格罗尼（Negroni）、新加坡司令（Singapore Sling）、吉姆雷特（Gimlet）

二、威士忌（Whisky / Whiskey）🥃

谷物蒸馏烈酒中风味最丰富、最讲究产区与陈年的一类。拼写区别：苏格兰写 Whisky，爱尔兰与美国写 Whiskey。

  • 成分：以大麦、玉米、黑麦、小麦等谷物为原料，经糖化、发酵、蒸馏后在橡木桶中陈年。原料、泥煤、橡木桶类型共同决定风味（花果、烟熏、海盐、焦糖……）。
  • 分类：
    • 按原料：
      • 麦芽威士忌（Malt）：只用麦芽酿制，苏格兰单一麦芽是代表，风味最鲜明
      • 谷物威士忌（Grain）：麦芽+玉米等谷物，口感轻盈，多用于调和
      • 调和威士忌（Blended）：麦芽与谷物勾兑，占市场主流（如尊尼获加）
      • 波本（Bourbon）：玉米≥51%，美国肯塔基代表，带香草焦糖甜
      • 黑麦威士忌（Rye）：黑麦≥51%，辛香料感更重
    • 按产区：苏格兰（Scotch）、爱尔兰（Irish）、美国波本/田纳西、日本、加拿大
  • 产区：苏格兰（斯佩塞、高地、艾雷岛、低地、坎贝尔镇等，风格各异）、爱尔兰、美国肯塔基州（波本重镇）、日本（山崎、白州、余市）、加拿大，台湾噶玛兰近年也声名鹊起。
  • 主要品牌：
    • 苏格兰：尊尼获加（Johnnie Walker）、芝华士（Chivas Regal）、麦卡伦（Macallan）、格兰菲迪（Glenfiddich）、拉弗格（Laphroaig，泥煤代表）
    • 美国：杰克丹尼（Jack Daniel’s）、占边（Jim Beam）、四玫瑰（Four Roses）
    • 日本：山崎（Yamazaki）、白州（Hakushu）
    • 爱尔兰：詹姆森（Jameson）
  • 代表调酒：老式（Old Fashioned）、曼哈顿（Manhattan）、威士忌酸（Whiskey Sour）、薄荷朱利普（Mint Julep）、威士忌高球（Highball）

三、白兰地（Brandy）🍾

以水果为原料蒸馏的烈酒统称，通常指葡萄白兰地。法国干邑是其王冠。

  • 成分：以葡萄（干邑使用白玉霓 Ugni Blanc 等品种）发酵后蒸馏，再于橡木桶中陈年。苹果、樱桃、梨等其他水果也能蒸馏出白兰地。
  • 分类：
    • 按陈年/颜色（由浅到深）：
      • 未陈年：透明无色，果香清新（如葡萄生命之水 Eau-de-vie）
      • 陈年：橡木桶酿出琥珀色，带香草、果干、木质香
      • 陈年等级：VS（≥2年）→ VSOP（≥4年）→ XO（新规≥10年）
    • 按产地/原料：
      • 干邑（Cognac）：法国法定产区，工艺与产区双重限定，最为知名
      • 雅文邑（Armagnac）：历史更古老，风格更粗犷厚实
      • 卡尔瓦多斯（Calvados）：苹果白兰地，产自法国诺曼底
      • 格拉帕（Grappa）：用葡萄渣酿造的意大利白兰地
  • 产区：法国干邑（大香槟区、小香槟区等六区）、雅文邑、诺曼底；西班牙、美国加州、秘鲁（皮斯科）等地亦有产出。
  • 主要品牌：轩尼诗（Hennessy）、人头马（Rémy Martin）、马爹利（Martell）、拿破仑（Courvoisier）、卡慕（Camus）
  • 代表调酒：边车（Sidecar）、白兰地亚历山大（Brandy Alexander）、法国情怀（French Connection）、B&B

四、伏特加（Vodka）🧊

追求纯净无味的「中性烈酒」，作为基酒几乎不抢味，调酒师最爱用它来承载其他风味。

  • 成分：传统上用谷物（小麦、黑麦、大麦、玉米）或土豆为原料，现代亦有甜菜糖蜜等；经多次蒸馏与活性炭过滤，追求清冽纯净。
  • 分类：
    • 按原料：
      • 谷物伏特加：小麦、黑麦、大麦等谷物酿制，最常见
      • 土豆伏特加：口感更圆润、带奶油感（如雪树）
      • 葡萄伏特加：果味更清爽（如灰雁）
    • 按风格：标准伏特加 vs 精品/工艺伏特加（Craft）；调味伏特加（Flavoured）
    • 原产地法规：部分国家对「伏特加」一词有产地限定（如波兰、瑞典）
  • 产区：俄罗斯、波兰（品质公认出众）、瑞典、芬兰、法国、美国
  • 主要品牌：绝对（Absolut，瑞典）、灰雁（Grey Goose，法国）、斯米诺夫（Smirnoff）、雪树（Belvedere，波兰）、白鲸（Beluga，俄罗斯）、芬兰（Finlandia）
  • 代表调酒：莫斯科骡子（Moscow Mule）、螺丝刀（Screwdriver）、血腥玛丽（Bloody Mary）、白色俄罗斯（White Russian）、大都会（Cosmopolitan）

五、朗姆酒（Rum）🏝️

甘蔗的烈酒，自带加勒比海的甜润与热带气息，是热带鸡尾酒的灵魂。

  • 成分：以甘蔗汁、糖蜜（molasses）或甘蔗糖浆为原料发酵蒸馏，再按风格选择是否陈年。甘蔗的「贵贱」与蒸馏方式决定了风味走向。
  • 分类：
    • 按颜色/陈年：
      • 白朗姆（White / Silver）：未陈年或陈年极短，活性炭过滤去掉颜色，酒体清澈透明、风味干净清淡，几乎不抢味，适合清爽鸡尾酒（莫吉托、代基里）
      • 黑朗姆（Dark）：多经橡木桶陈年，颜色深（有的还会加焦糖调色），风味浓郁厚重，带焦糖、红糖、香草气息，适合重口味调酒（自由古巴、迈泰）或纯饮
      • 金朗姆（Gold）、陈年朗姆（Aged）：介于白黑之间，属中度陈年
    • 按产地风格：英式重酯重味（牙买加）、法式农业朗姆（Rhum Agricole，甘蔗汁酿制，马提尼克岛有 AOC 认证）、西式清淡（古巴、波多黎各）、巴西卡莎萨（Cachaça，甘蔗汁酿制）
    • 其他：香料朗姆（Spiced）、高度朗姆（Overproof，酒精度高）
  • 产区：加勒比群岛（古巴、牙买加、波多黎各、巴巴多斯、马提尼克）、巴西、中南美洲、东南亚（菲律宾）
  • 主要品牌：百加得（Bacardi）、哈瓦那俱乐部（Havana Club）、摩根船长（Captain Morgan）、外交官（Diplomático）、阿普尔顿（Appleton，牙买加）、戈斯林（Gosling’s，百慕大）
  • 代表调酒：莫吉托（Mojito）、代基里（Daiquiri）、自由古巴（Cuba Libre）、椰林飘香（Piña Colada）、迈泰（Mai Tai）

六、龙舌兰（Tequila）🌵

墨西哥的骄傲，以「龙舌兰」这种植物为原料，是唯一把「墨西哥」写进名号的六大基酒。

  • 成分：以蓝色韦伯龙舌兰（Blue Weber Agave）的茎心（长得像凤梨的 piña）蒸煮、榨汁、发酵、蒸馏而成。纯正的龙舌兰酒标榜「100% de Agave」。
  • 分类：
    • 按陈年：
      • 白/银色（Blanco）：未陈年或≤2个月，透明清澈，风味最纯粹
      • 微陈（Reposado）：2个月–1年，轻度桶味
      • 陈年（Añejo）：1–3年，琥珀色、木桶香明显
      • 特级陈年（Extra Añejo）：>3年，醇厚接近威士忌
    • 按颜色（金/银）：银（Silver / Blanco，未陈年，透明清澈、最纯粹）、金（Gold / Oro，极短陈年或添加焦糖色调色，呈金黄、微甜）
    • 按纯度：100% 龙舌兰 vs 混合龙舌兰（Mixto，含龙舌兰糖≥51%，其余为其他糖类）
    • 近亲：梅斯卡尔（Mezcal），可用 200 多种龙舌兰酿造，地炉烘烤带来标志性烟熏味；核心产区瓦哈卡（Oaxaca），分级同龙舌兰（Joven / Reposado / Añejo）
  • 产区：墨西哥哈利斯科州（Jalisco）为核心产区，另有纳亚里特、瓜纳华托等法定区域；拥有原产地命名保护（DO），只有指定区域的产品才能叫 Tequila。
  • 主要品牌：豪帅快活（José Cuervo）、唐胡里奥（Don Julio）、培恩（Patrón）、埃雷杜拉（Herradura）、卡萨米戈斯（Casamigos）、1800
  • 代表调酒：玛格丽特（Margarita）、龙舌兰日出（Tequila Sunrise）、帕洛玛（Paloma）、墨西哥骡子（Mexican Mule）

鸡尾酒的其他部分

基酒是主角，其余都是「配角」——味美思、利口酒、苦精、糖浆、果汁，负责甜、苦、香、酸这些层次

味美思（Vermouth）

强化葡萄酒 + 草本香料浸渍

  • 甜味美思（Sweet / Rosso）：红色、甜润带草药苦香（代表：Carpano Antica、Martini Rosso）（用在哪：尼格罗尼、曼哈顿）
  • 干味美思（Dry）：透明干爽（代表：Noilly Prat）（用在哪：马天尼）
  • 白味美思（Bianco）：介于两者之间，微甜清爽（用在哪：马天尼的柔和变体）

橙味利口酒（Orange Liqueur）

  • 君度（Cointreau）：透明、甜橙皮香纯净（用在哪：玛格丽特、边车、大都会）
  • 橙皮甜酒（Triple Sec / Curacao）：常呈蓝色库拉索（用在哪：迈泰）
  • 柑曼怡（Grand Marnier）：干邑 + 橙皮，更醇厚（用在哪：边车变体、热饮/纯饮）

苦味利口酒（意大利系）

  • 金巴利（Campari）：橙皮 + 草药，苦中带甜、猩红色（用在哪：尼格罗尼、金巴利苏打）
  • 阿佩罗（Aperol）：比金巴利更甜更淡（用在哪：阿佩罗橙光 Spritz）
  • 费奈特（Fernet-Branca）：极苦草药（用在哪：餐后纯饮）

杏仁 / 香料类

  • 阿玛雷托（Amaretto）：杏仁香（用在哪：教父、法国情怀）
  • 杏仁糖浆（Orgeat）：无酒精杏仁糖浆（用在哪：迈泰、僵尸）
  • Falernum：朗姆 + 杏仁 + 香料糖浆（用在哪：僵尸）

苦精（Bitters）

  • 安高天娜（Angostura）：最通用（用在哪：古典、曼哈顿）
  • 裴乔氏（Peychaud’s）：萨泽拉克专用
  • 橙味苦精：橙香点缀（用在哪：马天尼、尼格罗尼）

糖浆（Syrup）

  • 单糖浆（1:1 糖:水）：调酸酒的基础甜度（用在哪：威士忌酸、代基里）
  • 石榴糖浆（Grenadine）：红色甜浆（用在哪：僵尸、龙舌兰日出）
  • 蜂蜜糖浆 / 枫糖浆（用在哪：威士忌酸变体、热饮）

果汁与气泡水

  • 柑橘汁：青柠（莫吉托、玛格丽特）、黄柠（边车、威士忌酸）、橙、葡萄柚
  • 气泡：苏打水（莫吉托、金菲士）、汤力水（金汤力）、姜汁啤酒、可乐（自由古巴）

吧台基本功：器具与手法

量杯（Jigger）

计量的关键：先量准，再倒入

  • 两头杯型，常见 30/45ml、20/40ml 规格
  • 倒法：酒瓶口贴量杯内壁，倒至满杯缘即停，不洒不漏
  • 量完贴着摇壶/杯壁倒入，中间不隔手

冰杯（预冷酒杯）

  • 作用：让酒液保持低温、少化水；短饮（马天尼、古典、尼格罗尼）尤其重要
  • 做法：搅拌/摇荡前先在杯里装满冰（或冰+水），上桌前倒掉冰水、擦干

冰块

  • 大块冰 / 老冰：化水慢，搅拌类用（马天尼、古典、尼格罗尼）
  • 碎冰 / 刨冰：化水快，Tiki、莫吉托用（要快喝）
  • 大冰球：纯饮 / 古典，融化最慢
  • 原则：冰宁多勿少——冰越多，化水越慢，酒越不容易稀

吧勺与搅拌（Stir）

  • 吧勺：长柄螺旋勺，专供搅拌
  • 手法：勺背贴杯壁、绕圈轻搅 10–20 圈，不出气泡
  • 目的：充分混合 + 冰镇 + 轻微稀释

摇壶与摇荡（Shake）

  • 摇壶：波士顿壶（大杯+小杯，专业常用）、三段式 Cobbler（自带滤网，家用顺手）
  • 手法：双手握壶、虎口压紧，快速上下摇 10–15 秒，冰约占壶 2/3
  • 硬摇：先不加冰摇出泡沫（酸酒、代基里）
  • 目的：充分混合 + 迅速降温 + 打出泡沫

搅拌 or 摇荡，怎么选

  • 搅拌：配料全是酒（烈酒 + 利口酒/味美思），不含果汁——马天尼、尼格罗尼、曼哈顿、古典
  • 摇荡：配料含果汁/蛋/奶/糖浆，需要打散乳化——玛格丽特、边车、莫吉托、代基里、Tiki 类
  • 口诀：全酒搅拌，有汁就摇

收尾小细节

  • 滤冰：摇/拌后先滤冰再倒入杯
  • 装饰：青柠角/橙皮先擦杯口再入杯，逼出香气
  • 倒酒：瓶口贴杯、吧勺引流，避免滴漏
