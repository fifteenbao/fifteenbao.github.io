最近在折腾 / NOW

🌱 bonflow

问题：换盆、修剪和施肥之后，很难把每次操作与植物后续的变化联系起来。

我的做法：把生长记录作为核心体验，结合端侧植物识别，做成可随手使用的 iOS App。

目前：App 已完成并提供下载；识别准确度和素材仍在持续校准。

🤖 unit_bot

问题：实体产品的事实研究、设计取舍和成本判断分散在不同阶段，方案很难追溯到证据。

我的做法：以 PLANTS 为项目、PLANS 为方法论，把现状研究、精益设计、先进裁剪、价值创新和体系建设连成五阶段流程；用 12 个分工明确的角色编排任务，保留证据引用、输入指纹和结果校验。

目前：通用实现已放在 plants/，不绑定特定模型、行业或成本分类，提供跨 Agent 任务包、项目隔离，以及 should_cost、assembly、roi 等确定性计算；扫地机器人保留为行业案例。

→ 查看项目 · 查看通用实现 · 阅读早期开发记

⚙️ IPD Agents

问题：智能硬件从概念到开发涉及多角色判断，评审依据与决策过程容易散落。

我的做法：用角色、方法和命令组织多 Agent 协作，覆盖市场管理、需求管理、概念评审、开发验证到发布；由 COO 和 Board 对市场、技术与财务判断进行审核。

目前：已加入可选的 Demo 验证、TR1–6 技术评审和生命周期监控；决策框架也纳入用户主体性、全生命周期生态代价，以及收益与控制权的分配。智能拳击硬件曾用于概念阶段的 CDCP 演示。
